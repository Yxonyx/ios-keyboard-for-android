# Security reporting

Do not disclose exploit details or personal text in a public issue. Once the
repository is published, use GitHub's **Security → Report a vulnerability** if
private vulnerability reporting has been enabled by its maintainer. If that
option is unavailable, open a minimal issue requesting a private reporting route
without including the vulnerability details. There is currently no separate
security mailbox or response-time commitment.

Only the current development snapshot is maintained. No production support or
security audit is claimed. Use synthetic text when reproducing IME, clipboard,
dictionary parsing or speech-recognition problems.
